1. Restate the question and what the data must contain to answer it.
2. Write small, readable Python (pandas, statistics, csv) and run it with run_code. Print only what you need.
3. Check data quality first: row counts, missing values, duplicates, obvious outliers.
4. Report results with the exact numbers the code printed; never estimate a number you did not compute.
5. End with a short plain-language summary and any caveats about the data.
