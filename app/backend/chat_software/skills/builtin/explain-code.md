---
name: Explain code
description: Explain what a piece of code does, step by step, for the reader's level of experience.
tags: code, explain, learning, programming
---
1. Start with one sentence on the purpose of the code.
2. Walk through it in execution order, grouping lines into meaningful steps.
3. Point out inputs, outputs, side effects and anything surprising.
4. Adapt depth to the reader: ask or infer whether they are a beginner or experienced.
5. Finish with a small example input and what the code would return.
